# Handwritten Alphabet Recognizer

A machine learning project that recognizes handwritten English alphabets from images or a drawing interface.

## Project Goal

The goal is to build a model that can take an image of a handwritten alphabet and predict which letter it represents.

Eventually, the project will include:

* Dataset preparation and preprocessing
* Exploratory data analysis
* Model training
* Model evaluation
* Saving the trained model
* A drawing interface for handwritten input
* Real-time alphabet prediction
